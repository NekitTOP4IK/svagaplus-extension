# Changelog

---

## [1.1.0] — 26.07.2026

Релиз про надёжность и производительность. Пользовательских функций не добавлено.

### Исправлено

- Бейдж мог **навсегда** не появиться на сообщении, если запрос за данными сорвался —
  моргнула сеть, спал service worker, бэкенд ответил ошибкой. Сообщение помечалось
  как «бейджей нет» и больше никогда не переобрабатывалось, хотя цвет ника при этом
  оставался. Теперь сбой отличается от подтверждённого отсутствия бейджей, и такое
  сообщение возвращается в обработку.
- Запрос бейджей для более чем 100 зрителей отклонялся бэкендом целиком, после чего
  всем зрителям из этой пачки на 30 секунд записывалось «бейджей нет». Пачка нарезается
  по 100. Проявлялось при обновлении бейджей канала и при возврате на вкладку
  с людным чатом.
- Частично заполненный кэш зрителей выдавался как полный ответ: одного известного
  зрителя хватало, чтобы остальные остались без бейджей на весь срок жизни кэша.
- Очередь сообщений, накопленных при скрытой вкладке, росла без ограничений
  и удерживала в памяти уже удалённые из чата элементы. Ограничена 200 записями.
- Просроченные записи кэша бейджей не удалялись до смены канала: за долгий стрим
  накапливались десятки тысяч записей.
- Логины зрителей собирались по всему документу, а не только из сообщений чата —
  в запрос попадали имена из карточек, закреплённого сообщения и mod view.

### Изменено

- Попап переписан: три состояния аккаунта с кроссфейдом вместо скачков по высоте,
  скелетон загрузки, аватар с запасным вариантом, поддержка клавиатурной навигации
  и `prefers-reduced-motion`. Кнопка больше не исчезает во время подключения.
- Перерисовка чата при обновлении бейджей объединяется в один кадр: раньше каждое
  событие обходило документ четырежды, и пачка событий выполняла тысячи операций подряд.
- Бейджи социального рейтинга в пачке сообщений обрабатываются параллельно —
  это возвращает к работе группировку запросов, которая до этого собирала по одному.
- Подсказки бейджей работают через один обработчик на документ вместо трёх на каждый
  бейдж; прокрутка чата больше не ждёт их.
- Позиционирование подсказки не заставляет браузер пересчитывать раскладку
  при каждом наведении.
- Замены ников: регулярные выражения кэшируются, а обход интерфейса не выполняется
  вовсе, если у пользователя нет ни одной замены.

### Удалено

- Фоновый скрипт-дубликат, попадавший в обе сборки, — около 100 КБ мёртвого кода.
- Неиспользуемая страница подтверждения авторизации, открытая для twitch.tv.
- Легаси-сборщик `build.js`, собиравший нерабочее расширение.
- Вывод списка логинов зрителей канала в консоль браузера.

### Сборка и разработка

- Выходные каталоги разделены по каналам: `dist/{chrome,firefox}-{dev,prod}`.
  В каждый пишется `build-info.json` с каналом и вшитым адресом бэкенда.
- Скрипты подписи и упаковки отказываются работать со сборкой, собранной не в канале
  `prod`, — staging-сборку больше нельзя выпустить по ошибке.
- Закрыты уязвимости `fast-uri` и `serialize-javascript` (зависимости сборки,
  в поставку не попадали).
- Тесты подхватываются автоматически: было 11 файлов с ручным перечислением,
  стало 26.
- CI запускается на pull request и на `staging`, проверяет версию, канал и вшитый
  адрес во всех четырёх сборках.
- Починен тулчейн на Windows: упаковка без системного `zip`, тест манифеста Firefox
  без побочной сборки, нормализация окончаний строк.
